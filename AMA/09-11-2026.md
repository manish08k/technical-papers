**Date:** 09-11-2026

## Questions and Answers

### 1. Anoop Vantagodi: What is Encapsulation?
Bundling data and methods into one class and restricting direct access to the internals.

### 2. Khushi Rani: What Does the `__init__` Function Do?
It runs automatically when an object is created and sets up its initial attributes.

### 3. Kiran B L: What is the Use of the Pipe Operator?
In the shell, `|` passes one command's output as input to the next, and in Python it acts as bitwise OR, set union, or dict merge.

### 4. Kummari Amaresh: What is Inheritance?
A child class acquires the attributes and methods of a parent class, promoting code reuse.

### 5. Kuppireddy Sivashankara Reddy: Difference Between Instance Method and Class Method?
An instance method takes `self` and works on object data, while a class method uses `@classmethod`, takes `cls`, and works on class-level data.

### 6. Masarpu Jyothish: How to Upgrade System Applications/Packages in CLI?
Use `sudo apt update && sudo apt upgrade` (Debian/Ubuntu), `sudo dnf upgrade` (Fedora/RHEL), or `brew upgrade` (macOS).

### 7. Mohd Saad Shaikh: What is a Constructor?
A special method (`__init__` in Python) that initializes a new object when it is created.

### 8. Moyya Naveen: How to Remove a Directory?
Use `rmdir dirname` for an empty directory or `rm -r dirname` for one with contents.

### 9. Mudrakola Sai Pavan: What is the Use of `super()`?
It lets a child class access its parent's methods and constructor.

### 10. Neha Sunil Magadum: What are the 4 Pillars of OOP?
Encapsulation, Abstraction, Inheritance, and Polymorphism.

### 11. Palepu Veerababu: What are Class and Object?
A class is a blueprint, and an object is an instance created from that blueprint.

### 12. Parameswaran R: Difference Between `find()` and `index()`?
`find()` returns `-1` if the substring is not found, while `index()` raises a `ValueError`.

### 13. Pavan Kumar: What Does `self` Refer To?
The current instance of the class, used to access its attributes and methods.

### 14. Raghu B S: Difference Between `break` and `continue`?
`break` exits the loop entirely, while `continue` skips to the next iteration.

### 15. Shakthivel: What is the Use of the `pass` Keyword?
It is a do-nothing placeholder used where a statement is syntactically required.

### 16. Sunkara Prasanth: What is Abstraction?
Hiding implementation details and exposing only the essential interface.

### 17. Varad Rajesh Barbhai: Can a List be Appended in a Tuple?
You can't append to a tuple because it is immutable, but a list inside a tuple can be modified.
