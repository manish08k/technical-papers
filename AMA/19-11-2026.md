1. **Recursive Query:** A query that calls itself to retrieve hierarchical data, like employee-manager relationships.

2. **COUNT(1):** Counts the total number of rows in a table, including NULL values.

3. **Normalization:** Organizing data into tables to reduce duplication and maintain data consistency.

4. **DELETE, DROP and TRUNCATE:**
   - DELETE: Removes selected rows.
   - DROP: Deletes the entire table.
   - TRUNCATE: Removes all rows but keeps the table structure.

5. **Database:** An organized collection of data that we can store, access and manage.

6. **Can we call a function inside another function?** Yes, we can call one function inside another function.

7. **Why do we need normalization in SQL?** To avoid duplicate data and maintain data consistency.

8. **RANK():** Assigns ranks to rows. If two rows have the same rank, the next rank is skipped.

9. **UNIQUE Constraint:** Prevents duplicate values in a column.

10. **How to concatenate two strings in Python?** Using the `+` operator.
    ```python
    a = "Hello"
    b = "World"
    print(a + " " + b)
    ```

11. **Generator in Python:** A generator produces values one at a time using the `yield` keyword.

12. **How to remove whitespaces in SQL?** Using the `TRIM()` function.

13. **Built-in functions in Python:** `print()`, `len()`, `type()`, `input()`, `range()`, `sum()`, `max()`, `min()`.

14. **Which keyword is used to start a transaction?** `BEGIN` or `START TRANSACTION`.

15. **Use of Constraints:** Constraints apply rules to columns to maintain data accuracy. Examples: `PRIMARY KEY`, `FOREIGN KEY`, `UNIQUE`, `NOT NULL`.

16. **Difference between Iterable and Iterator:**
    - Iterable: An object we can loop through, like a list or tuple.
    - Iterator: An object that returns values one by one using `next()`.
